Working on this UI package¶

Read README.md, docs/source-contract.md and docs/views.md before changing behavior. This is a self-contained static application with fictional example data. Preserve the existing shared renderers and single navigation registry. No framework or additional registry is required to add a view.

Use English as the default UI language and retain the selectable German translation. Original source quotations keep their authored language. Identifiers and code comments are English. Use existing CSS tokens, semantic HTML, native controls and explicit keyboard focus. Keep source identity, dated assessment, assignment state and actual activity separate. A copied prompt is preparation and grants no execution authority.

Change shared behavior at its existing owner. Do not create a second demo-only controller. The static adapter is a separate boundary from UI/model code. A replacement project-source adapter must satisfy the existing contracts and explicitly select its own files; it must not require a personal vault or publish a source root implicitly.

Run node --check on changed JavaScript, rebuild the explicit synthetic assets when appropriate, and run check-package.cjs against a running static server at the actual deployment subpath. Exercise the changed task, keyboard path, narrow reflow, both color schemes and failure states. Record what actually ran; browser behavior and human acceptance are different stages.

Preserve the complete project/source/result/prompt paths, original dated wording, manual clipboard fallback, local preference error handling and unknown/empty states. Scope all demo storage to mission-control-demo keys. Reject delivery and canonical writes explicitly; never simulate a successful send or live agent. Do not introduce runtime CDN dependencies or credentials.

Publication is a separate operator decision. Review the explicit export manifest and selected source contents before any deployment. Public license notices remain intact. Changes to the surrounding method site need their own scope and review.
